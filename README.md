# 🚀 آموزشگاه هوش نو — سامانه وب و LMS

پروژه کامل Django با طراحی پاستل شاد برای مخاطبان ۱۲ تا ۲۴ سال.

## ساختار پروژه
```
hooshnoo_project/
├── manage.py
├── requirements.txt
├── db.sqlite3            (آماده — با داده نمونه)
├── hooshnoo_core/        تنظیمات و urlهای اصلی
├── core/                 خانه، درباره ما، تماس، سوالات متداول، تنظیمات سایت
├── courses/              دسته‌بندی، دوره، ثبت‌نام
├── accounts/             کاربر سفارشی (دانش‌آموز/مدرس/والد/مدیر)، پروفایل
├── lms/                  درس، تکلیف، آزمون، ارسال تکلیف
├── templates/            قالب‌ها (base.html و ...)
└── static/               css/style.css و js/main.js
```

## راه‌اندازی گام‌به‌گام

### ۱) نصب پیش‌نیازها (نیاز به Python 3.10+)
```bash
pip install -r requirements.txt
```

### ۲) مهاجرت دیتابیس
اگر `db.sqlite3` موجود است (داده نمونه دارد) این مرحله اختیاری است؛ در غیر این صورت:
```bash
python manage.py migrate
```

### ۳) درج داده‌های نمونه (۶ دوره واقعی + ادمین)
```bash
python manage.py seed_data
```

### ۴) ساخت کاربر مدیر (در صورت نیاز جداگانه)
```bash
python manage.py createsuperuser
```
یا از کاربر آماده استفاده کنید:
- نام کاربری: `admin`
- رمز عبور: `admin1234`

### ۵) اجرای سرور
```bash
python manage.py runserver
```
سپس در مرورگر:
- سایت: http://127.0.0.1:8000
- پنل مدیریت: http://127.0.0.1:8000/admin

## امکانات
- صفحه اصلی با کارت دوره‌های منتشرشده (مدیر از پنل اضافه می‌کند و بلافاصله در صفحه اصلی می‌آید)
- فهرست دوره‌ها با فیلتر زنده سن/سطح/دسته/جست‌وجو
- صفحه جزئیات دوره با سرفصل‌ها و ثبت‌نام
- ثبت‌نام، ورود و پنل کاربری
- مودال مشاوره شناور + ذرات پاستل متحرک
- طراحی واکنش‌گرا، راست‌به‌چپ، فونت وزیرمتن، بوت‌استرپ ۵ RTL
